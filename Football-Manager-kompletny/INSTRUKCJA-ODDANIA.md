# Lista kontrolna przed oddaniem

- [ ] Uzupełnij dane autora i przedmiotu, jeśli prowadzący tego wymaga.
- [ ] Wykonaj `npm install` oraz `npm start`.
- [ ] Otwórz `http://localhost:3000` i sprawdź wszystkie cztery sekcje.
- [ ] Ręcznie wykonaj testy z `docs/testy.md` i wpisz rzeczywiste wyniki.
- [ ] Otwórz PNG diagramów i sprawdź czytelność; sprawdź też pliki Mermaid na GitHubie.
- [ ] Sprawdź wymagany przez prowadzącego format oddania i podpisy/stronę tytułową.
- [ ] Nie dodawaj `node_modules/` ani `database.db` do repozytorium.

## Zakres i ograniczenia
Edycja zawodników i meczów jest dostępna przez endpointy PUT backendu, ale nie przez interfejs WWW. Projekt nie ma logowania, autoryzacji ani podziału ról. Testy są planem do ręcznego wykonania — nie oznaczono ich jako zaliczonych.
