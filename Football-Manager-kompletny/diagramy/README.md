# Diagramy

Diagram przypadków użycia: `zrodla_dot/01_przypadki_uzycia.dot`.

Diagramy aktywności i odpowiadające im diagramy sekwencji znajdują się jako pliki Markdown z kodem Mermaid. Każdy przypadek opisany w `docs/przypadki-uzycia/` ma diagram aktywności i sekwencji.

Diagram klas/modułów i ERD mają edytowalne źródła Graphviz w `zrodla_dot/`. Pliki PNG i SVG są generowane z tych źródeł.

Reguła modelowania: sekwencja pokazuje ścieżkę powodzenia. Operacje PUT są udostępnione w API, ale nie mają scenariusza formularza WWW.
