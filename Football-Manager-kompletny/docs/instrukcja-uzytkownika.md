# Instrukcja użytkownika

## Przegląd
Po otwarciu strony widoczny jest panel z liczbą zawodników, sumą goli, asyst i liczbą meczów. Kafelki skrótów prowadzą do list zawodników i terminarza.

## Zawodnicy
1. Wybierz **Zawodnicy** w menu.
2. Kliknij **Dodaj zawodnika**.
3. Wpisz imię i nazwisko, numer, pozycję oraz statystyki.
4. Kliknij **Zapisz zawodnika**. Numer koszulki musi być unikalny.
5. Aby usunąć gracza, kliknij **Usuń** przy jego wierszu i potwierdź operację.

## Terminarz
1. Wybierz **Terminarz**.
2. Kliknij **Dodaj mecz**.
3. Podaj przeciwnika i datę; opcjonalnie godzinę, miejsce i wynik.
4. Kliknij **Zapisz mecz**.
5. Aby usunąć spotkanie, kliknij **Usuń mecz** i potwierdź.

## Klasyfikacja strzelców
Wybierz **Klasyfikacja strzelców**. Lista jest sortowana malejąco według goli; przy remisie decyduje kolejność alfabetyczna nazwisk.

## Ograniczenia
W interfejsie WWW nie ma funkcji edycji istniejących zawodników ani meczów. Aktualizacja jest możliwa przez API PUT. Aplikacja nie ma kont użytkowników ani podziału uprawnień.
